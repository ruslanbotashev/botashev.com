Aeon / DevOps & infrastructure engineering

A new orbit for
a legacy game.

Keep the application. Modernize the way it reaches production.

The context

Aeon is a browser-based space-strategy game. My work was its infrastructure and operations, alongside the application developers and my other positions.

The delivery path

I modernized the legacy PHP application for containers and Kubernetes through packaging, deployment-supplied configuration and operational changes. Docker and Compose packaging covered the PHP/Nginx/PostgreSQL stack and a Node.js/MongoDB chat service.

Helm packaging, readiness checks, HTTPS/WebSocket routing and GitHub Actions publishing fed ArgoCD GitOps for the game, testing and shared infrastructure. Versioned promotion, rollback and self-healing reconciliation made delivery repeatable.

Operations across the lifecycle

My scope also included resilient Linux hosting, redundancy, load balancing, network security, hosting migrations, backup and recovery, secrets integration and cluster automation.

Application modernization through packaging, configuration and delivery.

My remit was infrastructure and delivery, alongside the application developers. This describes the modernization period; the existing game is now frozen and a new version is in development.

Period

August 2009 to approximately January 2022, with consulting thereafter.
