Software that reasons about network failures, then takes guarded action or escalates.

The engineering

At AWS I developed network-entity models, enriched incoming alerts from other systems, correlated root causes and mapped events to recovery tasks or escalation. Device-agnostic interfaces and reusable operations let network engineers build recovery workflows without owning every platform detail.

Global Border/Backbone

I designed and implemented automated mitigation for interface and BGP failures across the global Border/Backbone network. Work combined investigation, checks, guarded device actions and integration with the event-management pipeline.

More than 80% reduction in downtime associated with that interface/BGP remediation work.

Platform evolution

As part of the team, I co-designed a migration to modular remediation, implemented components and helped execute the production cutover. This was shared platform work.

Engineering beyond the code

I used alert coverage, escalation and mitigation data to identify automation gaps and inform networking teams' priorities. Device abstractions, code review and office hours helped network engineers turn investigations into recovery workflows.
